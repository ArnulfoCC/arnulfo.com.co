Árboles de decisión

Pensamiento Algorítmico · Unidad 3 · Escenario 5. Resumen de estudio con los ejercicios propuestos de la lectura resueltos.

1. Definición

Un árbol de decisión resuelve un problema evaluando expresiones lógicas: cada condición es VERDADERA o FALSA y, según el resultado, se sigue un camino. Un mismo problema puede resolverse con árboles distintos.

En este módulo solo se estudian árboles determinísticos, que no usan probabilidades. Los probabilísticos se ven en módulos posteriores.

2. Componentes y reglas

ComponenteQué contieneReglas
Nodo (óvalo)Una expresión lógica: relacional (a = b, n MOD 2 = 0) o con operadores lógicos (∧, ∨)El árbol empieza en un único nodo y nunca termina en un nodo.
RamaLa etiqueta V o FSalen siempre en pares, exactamente dos por nodo. Cada rama llega a un nodo o a una hoja; a cada nodo u hoja llega una sola rama.
HojaUn posible valor de la salidaEl árbol siempre termina en hojas.
  • Árbol mínimo: 1 nodo, 2 ramas y 2 hojas.
  • Conteo: en todo árbol, hojas = nodos + 1 y ramas = 2 × nodos.
  • Anidamiento: si una condición sale de la rama de otra, está anidada en ella. Dos condiciones que salen de ramas distintas del mismo nodo son independientes entre sí.
  • Relación con el Escenario 4: primero se modela el problema. Las entradas aparecen en los nodos y los valores de la salida en las hojas.

3. Ejemplos de la lectura

Par o impar

        n MOD 2 = 0
        V /       \ F
        PAR       IMPAR

Alternativa: con n MOD 2 = 1 en el nodo, la rama V lleva a IMPAR.

Tipo de triángulo (lados a, b, c)

                    a = b
              V /           \ F
            a = c            b = c
          V/    \F         V/    \F
   Equilátero  Isósceles Isósceles  a = c
                                  V/    \F
                            Isósceles  Escaleno

Caso de uso: a = 14, b = 16, c = 14 → a = b F → b = c F → a = c V → Isósceles.

Con operadores lógicos el árbol se simplifica: a = b ∧ a = c → Equilátero; si no, a = b ∨ a = c ∨ b = c → Isósceles; si no, Escaleno.

4. Ejercicios propuestos, resueltos

Problema 1 · El mayor de a, b y c

                 a ≥ b
            V /         \ F
          a ≥ c          b ≥ c
        V/    \F       V/    \F
       a       c       b       c

Caso de uso: a = 3, b = 7, c = 5 → a ≥ b F → b ≥ c V → 7.

Problema 2 · ¿Se puede formar un triángulo?

Desigualdad triangular: cada lado debe ser menor que la suma de los otros dos.

   a + b > c  ∧  a + c > b  ∧  b + c > a
           V /                 \ F
   Sí forma triángulo    No forma triángulo

Caso de uso: 2, 3 y 10 → 2 + 3 > 10 es F → no forman triángulo.

Problema 3 · ¿n es divisible entre 4?

   (n MOD 100) MOD 4 = 0
       V /         \ F
   Divisible    No divisible

Caso de uso: n = 1.316 → últimas dos cifras 16 → 16 MOD 4 = 0 → sí es divisible.

Problema 4 · Supermercado Doña Mechas

Tres niveles de anidamiento, 7 nodos y 8 hojas. c es el valor de la compra y cada hoja es lo que finalmente se paga (1 − descuento).

                              compra ≥ 300.000
                      V /                         \ F
                 tarjeta                          tarjeta
              V /       \ F                    V /       \ F
         efectivo     efectivo            efectivo      efectivo
         V/   \F      V/   \F             V/   \F       V/   \F
    0,75·c  0,83·c  0,80·c  0,85·c    0,88·c  0,97·c  0,93·c  1,00·c

Caso de uso del enunciado: $450.000, sin tarjeta y en efectivo → V, F, V → 0,80 × 450.000 = $360.000.

5. Para repasar

  • ¿Por qué nunca salen tres ramas de un nodo? Porque una condición lógica solo tiene dos resultados; para más opciones se anidan condiciones.
  • Un árbol con 7 nodos tiene 8 hojas y 14 ramas.
  • Con $200.000, tarjeta y pago en efectivo en Doña Mechas se paga 0,88 × 200.000 = $176.000.
